# التحقق من ED Audit 1.1.0 لويندوز

التاريخ: 30 أكتوبر 2026. الأساس: التطبيق المنشور `1793377044418`.

## نتائج مكتملة

- نجحت 39 حالة منطق وتحقق ملفات وسياسات سطح المكتب؛ لم تُسجل حالات فشل أو تخطٍّ في هذه المجموعة.
- نجح فحص TypeScript وبناء Vite للإنتاج.
- نجحت أربعة مسارات Electron على Linux من المصدر، ثم نجحت المسارات الأربعة على التطبيق المعبّأ داخل ASAR: العمل دون إنترنت وإدخال الكسور والحفظ وإعادة التشغيل؛ استيراد مصنف ناقص واستعادة JSON ورفض البنية التالفة؛ تصدير XLSX وCSV وPDF وإلغاء الإخراج؛ فشل التخزين ومنع الإغلاق غير المقصود وتنزيل نسخة الإنقاذ.
- نجح اختبار انتقال الحفظ بين مساري تشغيل منفصلين للتطبيق المعبّأ على Linux، والعودة إلى المسار الأول، باستخدام مجلد مراجعة ثابت.
- بُني ملفا NSIS للمثبّت والنسخة المحمولة بمعمارية x64. فُحصت بيانات الملف التنفيذي: اسم ED Audit، والإصدار 1.1.0، والأيقونة المرفقة.
- اجتازت الحزمتان فحص سلامة NSIS وفحص أرشيف التطبيق المضمّن. تطابقت بصمة ASAR المستخرج من كل حزمة مع ASAR المفحوص.
- تطابقت ملفات التشغيل السبعة داخل حزمة ويندوز مع ملفات التطبيق المعبّأ الذي اختُبر على Linux، بايتًا ببايت. لا تحتوي الحزمة على مجلد الاختبارات أو مساحة العمل أو ملفات المراجعات.
- أُنشئ ملف SHA256SUMS.txt للتحقق من التنزيل، وفُحصت بنية GitHub Actions وملف قفل التبعيات.

## ما يحتاج بيئة ويندوز أو اتصال GitHub

لم يُنفّذ المثبّت أو البرنامج على نظام Windows أصلي وقت إعداد هذا التقرير المحلي. يحتوي GitHub Actions على تشغيل الاختبارات على ويندوز، واختبار المثبّت بعد التثبيت، والتبديل إلى النسخة المحمولة، وإعادة التثبيت مع الاحتفاظ بالحفظ. راجع نتائج Actions الحالية في المستودع العام لمعرفة نتيجة هذه الفحوص. لا يُنشر إصدار GitHub تلقائيًا إلا بعد نجاح الوظيفة على ويندوز.

الاختبارات لا تشمل طابعة مادية، أو توقيعًا رقميًا، أو مطابقة طبية مع مصنف مرجعي معتمد. ملفات الإنتاج غير موقّعة رقميًا كما هو محدد للإصدار الأول.

## ملاحظات البناء

استُخدم Electron 45.1.0 وelectron-builder 26.18.0 من ملف القفل. ظهرت تحذيرات Vite المعروفة حول stream وحجم حزمة الواجهة؛ لم تمنع البناء أو اختبارات التشغيل.

تعذّر تشغيل حزمة Wine 11 الخاصة بأداة البناء في بيئة Linux الحالية بسبب غياب kernel32.dll. استُخدمت أداة UninstallerReader الموجودة أصلًا في electron-builder لاستخراج وسيط إزالة التثبيت، وهي الطريقة التي تستخدمها الأداة على macOS. لم يتغير مصدر التطبيق أو قالب المثبّت بسبب ذلك، وفُحصت سلامة الأرشيف الناتج. مسار GitHub Actions على ويندوز يستخدم البناء القياسي دون هذه المعالجة الخاصة بالمضيف.
