# ED Audit 1.2.0

- مراجعات مستقلة حسب المنشأة والفترة، محفوظة محليًا في أرشيف المراجعات.
- ترحيل الحفظ القديم إلى الأرشيف مع إبقاء بياناته الأصلية حتى الحذف الصريح.
- نقاط استعادة مؤرخة، ونسخة استرجاع للحالة الحالية قبل استعادة نسخة سابقة.
- نسخ JSON مؤرخة متوافقة مع النسخ القديمة؛ تنبيه عند فشل التخزين مع بقاء العمل في الواجهة.
- مقارنة فعلية لمحتوى تقارير PDF وCSV وExcel مع النتائج المعروضة، قبل التصحيح وبعده والتراجع عنه، ببيانات اصطناعية.
- مراقبة أسبوعية للتبعيات وبوابة اختبارات Linux قبل بناء ويندوز، دون تطبيق إصلاحات بالقوة.
- مثبّت ونسخة محمولة، وملف ZIP مستقل لكل منهما.

البيانات محلية وغير مشفّرة ولا تتزامن بين الأجهزة أو الموقع ونسخة ويندوز. نزّل نسخة JSON خارج الجهاز. النسخة غير موقّعة رقميًا. المطابقة الطبية المستقلة تحتاج مصنفًا مرجعيًا معتمدًا، ولم تُنجز ضمن هذا الإصدار.
