# دليل ED Audit لويندوز

## التشغيل والحفظ

اختر المثبّت لإضافة اختصارات البرنامج، أو شغّل النسخة المحمولة مباشرة. النسختان تعملان دون إنترنت ودون Node.js. تُحفظ مراجعتك تلقائيًا في حسابك على الجهاز، داخل `%APPDATA%\ED Audit`. لا يعني نقل الملف المحمول إلى جهاز آخر نقل البيانات؛ انقلها بواسطة نسخة JSON.

انتظر ظهور «محفوظ على الجهاز» قبل الإغلاق. عند امتلاء مساحة التخزين أو تعذر الحفظ، يبقى العمل في الواجهة ويظهر تحذير. نزّل نسخة JSON لحماية تعديلاتك. إزالة البرنامج لا تمسح ملفات الحفظ؛ لمسح المراجعة استخدم «مسح مساحة العمل» داخل البرنامج.

## نقل مراجعة الموقع إلى ويندوز

من الموقع افتح التقرير ونزّل نسخة JSON. افتح برنامج ويندوز واختر ملف JSON نفسه. لا توجد مزامنة تلقائية بين الموقع والبرنامج أو بين أجهزة ويندوز.

## استيراد وتصدير الملفات

اختر مصنف XLSX أو نسخة JSON، ثم راجع النتائج والتعاريف قبل اعتماد التصحيحات. لا ترفع ملفات أقدم بصيغة XLS أو ملفات محمية بكلمة مرور؛ صدّرها إلى XLSX أولًا. الحد الأعلى لحجم الملف 15 MB، مع حدود إضافية لحجم المحتوى المفكوك.

في التقرير تتاح نسخة JSON، وتقرير CSV، والطباعة أو حفظ PDF. تختار مكان الحفظ عبر نافذة ويندوز. لتصدير Excel معدل، اختر «تصدير Excel معدل — اختر الأصل» ثم اختر المصنف الأصلي المطابق. تحفظ نسخة جديدة وتُظلل الخلايا المعدلة بالأصفر. افتح النسخة الناتجة في Excel لإعادة حساب الصيغ قبل اعتمادها.

إذا تداخل تعديل مع صيغة مصفوفة أو جدول بيانات، سيطلب البرنامج تنفيذه داخل Excel. لا تُملأ البيانات الطبية الناقصة تلقائيًا.

## التحديث والتحقق من التنزيل

أغلق التطبيق، واحتفظ بنسخة JSON، ثم شغّل المثبّت الأحدث أو استبدل ملف النسخة المحمولة. يبقى مجلد الحفظ ثابتًا. لا يوجد تحديث تلقائي. لا تدعم هذه الحزمة Windows بمعمارية ARM أو أنظمة 32 بت.

الإصدار الأول غير موقّع رقميًا؛ قد يظهر تنبيه عن الناشر غير المعروف. قارن بصمة الملف بملف `SHA256SUMS.txt` المرفق، باستخدام PowerShell:

```powershell
Get-FileHash .\ED-Audit-1.1.0-win-x64-Setup.exe -Algorithm SHA256
Get-FileHash .\ED-Audit-1.1.0-win-x64-Portable.exe -Algorithm SHA256
```

اختبارات الجودة تستخدم بيانات اصطناعية. تدقيق التطبيق يدعم مراجعة البيانات ولا يثبت وحده صحة التعاريف الطبية؛ يلزم مرجع طبي معتمد لذلك.
