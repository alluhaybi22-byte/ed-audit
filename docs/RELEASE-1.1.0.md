# ED Audit 1.1.0 — Windows x64

- مثبّت ونسخة محمولة يعملان دون إنترنت على Windows 10 و11 x64.
- جميع إصلاحات التطبيق المنشور `1793377044418`، والحفظ التلقائي واستعادة المصنفات الناقصة.
- استيراد XLSX وJSON وتصدير نسخة Excel معدلة وCSV وJSON والطباعة وPDF.
- ملفات الحفظ ثابتة في حساب مستخدم ويندوز عبر التحديثات والتبديل بين النسختين.
- لا يحتاج التشغيل إلى Node.js؛ إعادة حساب صيغ المصنف المعدل تتطلب فتحه في Excel.

الإصدار غير موقّع رقميًا وقد يعرض ويندوز تنبيهًا بشأن الناشر. قارِن البصمات بملف SHA256SUMS.txt. اقرأ دليل WINDOWS-AR.md قبل الاستخدام. لا يتضمن الإصدار تحققًا طبيًا مستقلًا بمصنف مرجعي معتمد.
