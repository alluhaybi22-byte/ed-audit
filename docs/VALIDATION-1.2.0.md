# التحقق من ED Audit 1.2.0

تاريخ التحقق: 31 أكتوبر 2026. جميع المصنفات والبيانات المستخدمة اصطناعية.

- [تشغيل GitHub Actions على ويندوز وLinux](https://github.com/alluhaybi22-byte/ed-audit/actions/runs/41248515122) للمصدر `b181c28f897661c6e8eccbcddaaf47c651a4dfac`.
- 40 حالة اختبار للمنطق والملفات والقيود وإجراءات Electron، وفحص TypeScript ناجحة.
- سبع مجموعات تكامل IndexedDB في Chromium: الترحيل مرة واحدة، المراجعات المستقلة، احتفاظ النسخ، استعادة قابلة للتراجع، تراجع المعاملات عند امتلاء التخزين أو تعذر الكتابة، البيانات التالفة، وتصحيح ساعة الجهاز.
- سبع حالات واجهة ناجحة لكل من مصدر Electron والنسخة المعبأة والبرنامج المثبّت: التشغيل دون اتصال وعزل العرض، الحفظ وإعادة التشغيل، JSON الجزئي والتالف، التصدير، فشل الحفظ، الأرشيف والاستعادة، وترحيل الحفظ القديم.
- اختبار التبديل بين المثبّت والمحمول والعودة ثم إعادة التثبيت نجح مع بقاء المراجعة ونقطة استعادتها. يُنشئ الاختبار البيانات في الخطوة الأولى فقط، ولا يعيد إنشاء بيانات مفقودة في الخطوات اللاحقة.
- مقارنة جميع المؤشرات الثمانية وكل ملاحظات التدقيق بين الشاشة ونص PDF الفعلي وCSV، مع فحص ملف Excel المعدل، قبل تطبيق التصحيح وبعده والتراجع عنه. يظل عمود النموذج يعرض نتيجة المصنف الأصلية عمدًا.
- سبعة تدفقات أرشيف ناجحة على [الموقع المنشور](https://mi-yar-ed-audit-55b1qs.v2.appdeploy.ai/)، الإصدار `1793486072646`، مع خلو سجل الواجهة والطلبات من الأخطاء. ضُبط تباعد التذييل لتبقى أزراره قابلة للنقر فوق شارة الاستضافة. شهادة وكيل الاتصال في بيئة الاختبار استلزمت استثناء TLS داخل Chromium التجريبي فقط.
- بوابة Linux وفحص التبعيات ناجحان. تقرير npm audit: صفر تنبيهات لتبعيات التشغيل، و15 حزمة تطوير متأثرة بتنبيه متوسط واحد عبر سلسلة البناء؛ تقارير الفحص محفوظة ضمن مرفقات التشغيل. لا تُطبق تحديثات بالقوة.
- حزم ZIP مستقلة للمثبّت والمحمول، مع SHA-256 لكل ملف تنفيذي وملف مضغوط. لا يُنشر الإصدار قبل اكتمال الملفات السبعة المتوقعة؛ اختُبرت استعادة نشر مسودة ناقصة والتوقف عند فشل الرفع.
- نُزّلت ملفات الإصدار المنشورة وفُحصت أحجامها وبصماتها مقابل بيانات GitHub وملفات SHA-256. فُحصت سلامة CRC ومحتويات ZIP، وتطابقت بصمات الملفات التنفيذية داخلها ودليل الاستخدام مع النسخ المنشورة.

لإعادة الاختبارات، ثبّت Node.js 24 والتبعيات باستخدام `npm ci`، ثم شغّل `npm test` و`npm run typecheck` و`node tests/browser-library.mjs` (يلزم Chrome/Chromium، أو تعيين `AUDIT_BROWSER`). اختبارات Electron عبر `npm run build` ثم `npm run test:desktop`، واختبارات التثبيت الأصلية ضمن سير عمل ويندوز.

الاختبارات تثبت سلوك البرنامج في الحالات المختبرة؛ لا تُعد تحققًا طبيًا مستقلًا أو ضمانًا لخلوه من الثغرات. لم يتوفر مصنف مرجعي طبي معتمد. التخزين والنسخ المحلية غير مشفرة، وملفات ويندوز غير موقعة رقميًا، ولا توجد مزامنة أو آلية تحديث تلقائي.
