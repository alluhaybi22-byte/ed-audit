# ED Audit — تدقيق بيانات الطوارئ

نسخة محلية لويندوز تعمل دون إنترنت، تشترك مع تطبيق الويب في محرك التدقيق وواجهة المراجعات. تضم تدقيق XLSX وJSON، مراجعة النتائج والتعاريف، التصحيحات القابلة للتراجع، أرشيف مراجعات مستقل حسب المنشأة والفترة، نقاط استعادة مؤرخة، والتصدير إلى Excel وCSV وJSON وPDF.

[تنزيل الإصدار v1.2.0](https://github.com/alluhaybi22-byte/ed-audit/releases/tag/v1.2.0) · [اختبارات البناء](https://github.com/alluhaybi22-byte/ed-audit/actions/workflows/windows.yml) · [تفاصيل الإصدار](docs/RELEASE-1.2.0.md)

## الاستخدام على ويندوز

Windows 10 أو Windows 11، بمعمارية x64. لا يحتاج المستخدم إلى تثبيت Node.js أو Excel لتشغيل التدقيق.

- [ED-Audit-1.2.0-win-x64-Setup.zip](https://github.com/alluhaybi22-byte/ed-audit/releases/download/v1.2.0/ED-Audit-1.2.0-win-x64-Setup.zip): المثبّت، مع اختيار المجلد واختصارات سطح المكتب وقائمة ابدأ.
- [ED-Audit-1.2.0-win-x64-Portable.zip](https://github.com/alluhaybi22-byte/ed-audit/releases/download/v1.2.0/ED-Audit-1.2.0-win-x64-Portable.zip): نسخة محمولة تُشغّل مباشرة. فك الضغط أولًا.

النسختان تحفظان المراجعات في IndexedDB داخل `%APPDATA%\ED Audit` في حساب مستخدم ويندوز، وليس بجوار الملف المحمول. تُرحّل المراجعة القديمة تلقائيًا مرة واحدة. تحتفظ التحديثات وإزالة البرنامج بالبيانات. لا تُشغّل نسختين معًا للحفاظ على سلامة الحفظ. اقرأ [دليل ويندوز](docs/WINDOWS-AR.md).

الإصدار غير موقّع رقميًا؛ قد يظهر تنبيه من Windows SmartScreen بشأن الناشر غير المعروف. ملفات البصمات SHA-256 تتيح التحقق من سلامة التنزيل.

## التطوير والبناء

Node.js 24 وnpm. ثُبتت إصدارات Electron وelectron-builder في ملف القفل.

```sh
npm ci
npx --no-install install-electron
npm test
npm run typecheck
npm run build
npm run desktop:start
npm run test:desktop
npm run desktop:win
npm run checksums
node scripts/package-zips.mjs
```

يُوصى ببناء ويندوز على ويندوز. Linux يحتاج خادم عرض لاختبارات Electron، ويستخدم electron-builder حزمة Wine المحددة في الإعدادات لبناء المثبّت. الحزمة النهائية في `release/`. الأمر `npm run desktop:pack` يفيد في اختبار التطبيق المعبّأ على نظام التطوير.

## GitHub والإصدارات

المستودع: `alluhaybi22-byte/ed-audit`، عام بموافقة صاحبه. لا ترفع ملفات المرضى أو المراجعات أو ملفات `.env` أو مجلدات التبعيات والمخرجات. يحفظ `.gitignore` هذا الفصل؛ يبقى محتوى الملفات المراد رفعها مسؤولية المطور.

يشغّل GitHub Actions اختبارات المنطق والأنواع وفحص التبعيات على Linux أولًا، ثم اختبارات IndexedDB وElectron على ويندوز، ثم يبني المثبّت والنسخة المحمولة ويختبر التطبيق بعد تثبيته والتبديل بين النسختين وإعادة التثبيت. تشمل الاختبارات مقارنة محتوى PDF وCSV وExcel بالشاشة قبل التصحيح وبعده والتراجع عنه. تبقى ملفات البناء وأدلة الاختبار ضمن Actions لمدة 30 يومًا؛ يُنشأ الإصدار الدائم الموافق لرقم package.json بعد نجاح بناء main أو وسم الإصدار، مع ZIP مستقل لكل نسخة. تُحفظ ملفات أي إصدار منشور سابقًا دون استبدال. صلاحية الكتابة مخصصة لوظيفة نشر الإصدار فقط.

يراقب Dependabot التبعيات أسبوعيًا. تُحفظ تقارير npm audit الكاملة وتقارير تبعيات التشغيل؛ تمنع الثغرات العالية أو الحرجة في تبعيات التشغيل النشر. تُراجع ثغرات أدوات البناء يدويًا دون تحديثات قسرية.

للحصول على المصدر وتطويره من جهازك:

```sh
git clone https://github.com/alluhaybi22-byte/ed-audit.git
cd ed-audit
npm ci
npm run build
```

يلزم تسجيل دخول GitHub على جهاز المطور. لا تحفظ رموز الدخول في المشروع.

## البيانات وحدود التدقيق

المصنف يُعالج محليًا. البيانات ونقاط الاستعادة غير مشفّرة. لا توجد خدمة خلفية أو مزامنة أو تحديث تلقائي. احتفظ بنسخة JSON خارج الجهاز؛ مسح بيانات المتصفح قد يحذف أرشيف الموقع. تعرض الواجهة ملفات إضافية أو أوراقًا ناقصة كملاحظات تدقيق؛ الاستعادة لا تختلق بياناتها. التحقق الطبي المستقل ما زال يحتاج مصنفًا مرجعيًا معتمدًا. جميع الاختبارات المرفقة تستخدم بيانات اصطناعية.
