# ED Audit — تدقيق بيانات الطوارئ

نسخة محلية لويندوز تعمل دون إنترنت، مستندة إلى مصدر التطبيق المنشور `1793377044418` بتاريخ 30 أكتوبر 2026. تضم تدقيق XLSX وJSON، مراجعة النتائج والتعاريف، التصحيحات القابلة للتراجع، الحفظ التلقائي، والتصدير إلى Excel وCSV وJSON وPDF.

## الاستخدام على ويندوز

Windows 10 أو Windows 11، بمعمارية x64. لا يحتاج المستخدم إلى تثبيت Node.js أو Excel لتشغيل التدقيق.

- `ED-Audit-1.1.0-win-x64-Setup.exe`: المثبّت، مع اختيار المجلد واختصارات سطح المكتب وقائمة ابدأ.
- `ED-Audit-1.1.0-win-x64-Portable.exe`: نسخة محمولة تُشغّل مباشرة.

النسختان تحفظان المراجعة في `%APPDATA%\ED Audit` داخل حساب مستخدم ويندوز، وليس بجوار الملف المحمول. تحتفظ التحديثات وإزالة البرنامج بالبيانات. لا تُشغّل نسختين معًا للحفاظ على سلامة الحفظ. اقرأ [دليل ويندوز](docs/WINDOWS-AR.md).

الإصدار غير موقّع رقميًا؛ قد يظهر تنبيه من Windows SmartScreen بشأن الناشر غير المعروف. ملفات البصمات SHA-256 تتيح التحقق من سلامة التنزيل.

## التطوير والبناء

Node.js 24 وnpm. ثُبتت إصدارات Electron وelectron-builder في ملف القفل.

```sh
npm ci
npx --no-install install-electron
npm test
npm run typecheck
npm run build
npm run desktop:start
npm run test:desktop
npm run desktop:win
npm run checksums
```

يُوصى ببناء ويندوز على ويندوز. Linux يحتاج خادم عرض لاختبارات Electron، ويستخدم electron-builder حزمة Wine المحددة في الإعدادات لبناء المثبّت. الحزمة النهائية في `release/`. الأمر `npm run desktop:pack` يفيد في اختبار التطبيق المعبّأ على نظام التطوير.

## GitHub والإصدارات

المستودع: `alluhaybi22-byte/ed-audit`، عام بموافقة صاحبه. لا ترفع ملفات المرضى أو المراجعات أو ملفات `.env` أو مجلدات التبعيات والمخرجات. يحفظ `.gitignore` هذا الفصل؛ يبقى محتوى الملفات المراد رفعها مسؤولية المطور.

يشغّل GitHub Actions الاختبارات على ويندوز ثم يبني المثبّت والنسخة المحمولة ويختبر التطبيق بعد تثبيته والتبديل بين النسختين وإعادة التثبيت. تبقى ملفات البناء ضمن Actions لمدة 30 يومًا؛ يُنشأ الإصدار الدائم الموافق لرقم package.json بعد نجاح بناء main أو وسم الإصدار. تُحفظ ملفات أي إصدار منشور سابقًا دون استبدال. صلاحية الكتابة مخصصة لوظيفة نشر الإصدار فقط.

للحصول على المصدر وتطويره من جهازك:

```sh
git clone https://github.com/alluhaybi22-byte/ed-audit.git
cd ed-audit
npm ci
npm run build
```

يلزم تسجيل دخول GitHub على جهاز المطور. لا تحفظ رموز الدخول في المشروع.

## البيانات وحدود التدقيق

المصنف يُعالج محليًا. لا توجد خدمة خلفية أو مزامنة أو تحديث تلقائي. تعرض الواجهة ملفات إضافية أو أوراقًا ناقصة كملاحظات تدقيق؛ الاستعادة لا تختلق بياناتها. التحقق الطبي المستقل ما زال يحتاج مصنفًا مرجعيًا معتمدًا. جميع الاختبارات المرفقة تستخدم بيانات اصطناعية.
